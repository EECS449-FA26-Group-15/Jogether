# Week 3 implementation handoff

## Current scope

- `validate_request` checks the four answers (unchanged from week 2).
- `landmarks.jac` lists 8 draft landmarks per area (#4).
- `plan_route` is one ByLLM call that turns a request and that area's
  landmarks into a `RouteResult`. `generate_route` checks the output and
  retries once (#5).
- `jac run --no-takeover cli.jac --generate` runs it on a local Ollama model. Without the
  flag, the CLI only validates, so CI never calls a model.
- Week 8 demo: the repo is now a Jac web app. `jac run` serves the page in
  `frontend.jac`, which calls `plan_run` in `planner.jac`. Before the LLM call,
  landmarks are filtered by time of day, and the check now caps a route at 6
  waypoints. The request also carries an optional free-text wish (`notes`).

- Better routes (branch `feat/better-routes`): 46 landmarks with tags and
  elevation, walking distances for every pair across areas (`geo_data.jac`,
  generated by `tools/build_geo.py`). Routes come in three shapes (loop,
  out-and-back, one-way), can start at a chosen landmark or the landmark
  nearest a typed address, and laps are only a fallback. A second ByLLM call
  (`parse_notes`) turns the free-text note into structured preferences that
  code scores candidates with, so "along the river, no hills" changes which
  routes the model gets to choose from. The CLI takes `--start`, `--shape`
  and `--notes`.

- Three routes, map and address (branch `feat/three-routes-map-address`,
  November 13): the page no longer has a start landmark menu. A typed address
  goes to Nominatim, the nearest landmark within 2 km becomes the start, and
  the area follows that landmark (`start_for_address` in `planner.jac`). One
  ByLLM call, `plan_routes`, describes all three measured options; picks that
  fail the check are dropped (`generate_routes` in `routes.jac`). `maps.jac`
  computes, on the server, the OpenStreetMap tiles and the OSRM walking path
  for each route, and the page draws them as SVG; the runner taps a card to
  see the full route. Tests cover the address matching, the choice filtering
  and the map geometry without the network.
